🔥 Firebase Setup

Для мультиплеера нужно настроить Firebase Realtime Database

1. Создай проект Firebase

  1. Перейди на console.firebase.google.com
  2. Нажми Add project
  3. Введи имя: infinite-tictactoe
  4. Отключи Google Analytics (не нужен)
  5. Нажми Create project

2. Включи Realtime Database

  1. В консоли Firebase: Build → Realtime Database
  2. Нажми Create Database
  3. Регион: europe-west1
  4. Правила: Start in test mode (для разработки)

3. Получи конфиг

  1. Нажми на шестерёнку → Project settings
  2. Прокрути вниз до Your apps
  3. Нажми на иконку Web (</>)
  4. Введи имя: tictactoe-web
  5. Скопируй firebaseConfig объект

4. Введи данные

5. Скопируй файл

После генерации сохрани файл как js/config.js в папке проекта
